# agency-agents-zh 提示词质量评审（纯文本评审）

> 2026-08-23。抽读 12+1 个代表性角色原文（WSL `/opt/agency-agents-zh/`），每个完整细读。
> 评分：每维 好=2 / 中=1 / 差=0，满分 12。"套壳"维：换角色名后提示词仍成立=模板套壳记 0 分。

## 一、总评

这套库明显存在**两代品质**：一批是英文母库的翻译填充件（engineering/testing/design/support 里大量
"Agent 人格"模板：身份与记忆→核心使命→关键规则→代码示例→工作流程→成功指标，结尾统一一句"你的详细
方法论在你的核心训练中"——这是英文原稿 "refer to your core training" 的直译残留）。这批提示词正确但空泛，
满是"实施适当的错误处理""遵循最佳实践"式的正确废话，成功指标全是拍脑袋数字，对模型增量知识接近零。
另一批是**真正做过中文本土化重写**的角色（marketing 中国平台系、legal、hr、sales、product、finance）：
有《民法典》第 585 条违约金调减、e签宝/法大大电子签章对比、Boss直聘/猎聘/拉勾渠道差异与秋招春招节奏、
小红书蒲公英报备与限流词库、Outbound 信号三梯队与回复率基准分层——这些是模型先验里薄弱、写了真能改变
行为的领域知识，交付物模板（审查意见书、投放排期表、PRD/RICE）拿来就能用。整体对比主流 coding agent
的内置 subagent 提示词（Claude Code 式短小、重工具纪律轻人设表演）：本库优秀个体在**领域密度**上超过
主流水准，但工程类普遍缺工具使用纪律、多人设戏剧和空洞指标；翻译质量本身是地道的中文，不是机翻腔。

## 三、分领域结论

**写得真好、值得纳入舰队（按优先序）**
- `legal/`（合同审查）：全场最佳，法条到平台到模板全链路本土化，可直接投产。
- `hr/`（招聘）：中国招聘市场实况浓度极高，Boss直聘打法/背调/社保实操齐备。
- `marketing/` 中国平台系（小红书 operator、抖音/B站/知乎/私域/百度SEO 同风格可推定）：本土化最深的板块。
  注意 xiaohongshu-operator 与 -specialist 两件重叠，取 operator。
- `sales/sales-outbound-strategist`、`product/product-manager`、`finance/finance-financial-analyst`、
  `marketing-growth-hacker`：方法论一流的国际范本，纳入前需做一轮国内场景适配（企微/飞书替代 LinkedIn/Loom，
  预算单位、Google Optimize 已死等）。

**凑数/套壳、不值得单独纳入**
- `engineering/` 通用开发类（前端/后端/SRE/API 等"Agent 人格"件）：同一英文模板的翻译填充，内容是模型
  先验里已有的常识，结尾还让模型"参考自己的核心训练"。当 subagent 用不如自己写 20 行任务简报；
  少数含真材实料的例外（如 wechat-mini-program-developer、feishu/dingtalk-integration 等中国栈角色）值得抽查后再定。
- `support/`、`testing/` 大部分、`design/` 部分人设件：官僚模板或脚手架残留，增量价值低。
- 库里 specialized/ 下大量 CXO/猎奇角色（livestock-archive-auditor 之类）未抽读，按此规律预期质量参差，纳入前逐一过审。

## 四、最终判断

**部分有用**——这不是一支整齐的战队，而是"约三分之一的精品本土化角色 + 三分之二的英文模板翻译填充"：
法务/HR/中国平台营销这几类确实有用、拿来即战；工程与支持类是花架子，模型本来就会，套壳无疑。
纳编策略：按上表挑 8-10 个精品入队，其余不装，别被 400+ 角色的数量唬住。
