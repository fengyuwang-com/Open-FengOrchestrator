# 视觉定调（北极星的一部分，改风格需老板拍板）

**总纲：老登审美。** 用户（董事长）原话裁定：现版"像小学生做的玩具，老登的审美呢"。设计靶心是**私人银行黑金 / 上市公司年报首页 / 奢侈品牌官网**，不是科技极客风。

- **配色**：黑金帝国——深墨黑底（#0a0a0c 级）+ 香槟金/鎏金主色（#c9a45c 系）+ 朱砂红点缀（#c0392b 级，只用于涨幅/重点）。**禁用霓虹青/赛博绿/紫**，那是网吧审美。
- **字体**：中文标题用宋体类衬线（思源宋体/霞鹜宋），大数字用衬线或 Didot 风格西文，正文思源黑体。拒绝七段码/JetBrains Mono 的"机房感"。
- **质感**：鎏金细线框（1px 金线 + 微弱金色辉光）、丝绸质感粒子（金箔漂浮，不是像素星星）、大理石/绸缎般的深色渐变背景。对标：劳斯莱斯官网、茅台年报、招商银行私人银行、Aman 度假村官网。
- **动效**：慢、稳、贵。开场金箔粒子汇聚成"豐"字或鎏金徽章 → 标题宋体逐字浮现。缓动用长缓出，禁止弹跳/闪烁/故障风。
- **构图**：大量留白 + 居中构图 + 超大标题字。一屏一个重点，像翻奢侈品画册，不塞满仪表盘。
- 数据可视化：金色为主的数据图表，细金线，无霓虹。参考高盛/摩根年报图表配色。
- 技术：GSAP 3 + Lenis、three.js（金箔粒子/星河）、ECharts 金色主题、DataV 装饰换为金线雕花感边框。
