# 安全策略

webcli 会打开一个**可执行任意命令**的交互式 shell，安全是首要关注点。
本文件说明项目安全设计、已知风险与漏洞报告方式。

## 支持版本

| 版本 | 支持状态 |
|------|----------|
| 0.3.x | ✅ 当前开发版本，接受漏洞报告 |
| 更早版本（0.1.x / 0.2.x，Python 版） | ❌ 已停止维护，不再接受漏洞报告 |

## 报告漏洞

如果你发现了安全漏洞，**请不要公开披露**（不要发 issue、不要发 PR），请通过以下任一渠道私下报告：

- 邮箱：`security@example.com`（占位，待维护者更新）
- 或：在 GitHub 仓库使用 **Security Advisory**（私密）功能创建报告（占位，待仓库启用）

请在报告中包含：

1. 受影响版本；
2. 漏洞描述与复现步骤（尽量精简，附最小复现脚本）；
3. 影响评估（可导致什么后果）；
4. 如已尝试修复，附补丁建议。

维护者会在 72 小时内回复确认，并在修复发布后与报告者协商披露时间。
常规问题（功能、用法）请走 issue，勿占用安全渠道。

## 安全设计

本项目奉行"**网络层隔离为主、应用层令牌为辅**"模型：

### 1. 网络层隔离（部署者责任，主要的访问控制）

- **默认绑定 `127.0.0.1`**：出厂默认只监听本机回环地址，不对外。
- **推荐 Tailscale 私网部署**：生产环境通过 `WEBHOST=<tailscale-ip>` 绑定
  Tailscale 私网 IP，访问面收敛到自有设备网络，公网不可达（详见 README
  「部署到 Tailscale」）。
- **WebSocket 不受浏览器同源策略约束**：不要指望"前端只走同源"来限制访问，
  任何能连到 `/term` 端点的客户端都等同于坐在主机前操作。

### 2. 应用层令牌与审计（内置）

- **可选 WEBTOKEN 鉴权**：设置环境变量 `WEBTOKEN` 后，`/term` 连接必须携带
  `?token=<值>` 查询参数，不匹配则以 close 1008 拒绝。未设置时仅依赖网络层隔离，
  **生产环境务必设置**。
- **审计日志**：每个会话结束时追加一行 JSON 到 `webcli/audit.log`，记录来源 IP、
  shell、时长（秒）与退出码。日志仅追加、不覆盖，供事后审计与取证。

### 3. 无执行层护栏（与旧版的关键差异）

0.3.0 起为 **ConPTY 真终端直通**模式：输入原样进入交互式 shell，后端**无法**逐条
拦截高危命令，也**没有**二次确认机制（旧版 Python 单命令模式的高危判定已随重写移除）。
安全完全依赖**网络层隔离 + WEBTOKEN 令牌**，部署者必须自行保持操作纪律。

## 威胁模型与已知限制

| 威胁 | 状态 | 说明 |
|------|------|------|
| 任意命令执行（RCE） | 功能即风险 | `/term` 设计上就打开交互式 shell；只能靠网络隔离 + 令牌防暴露 |
| 未授权访问 | 有缓解 | 默认 `127.0.0.1` + 可选 `WEBTOKEN`；未设令牌且绑错地址（如 `0.0.0.0`）等于完全开放 |
| 高危命令误执行 | **无护栏** | 真终端直通模式无法逐条拦截高危命令（`del`、`format` 等），无二次确认；依赖网络层 + 令牌 |
| 令牌泄露/嗅探 | 需注意 | `WEBTOKEN` 经查询参数传输，可能出现在代理/访问日志；建议叠加网络层隔离使用 |
| 日志泄露 | 低风险 | `audit.log` 含来源 IP 与 shell 信息，注意文件权限与备份 |
| PTY 进程残留 | 受保护 | 连接断开即销毁对应 ConPTY 会话；异常情况建议部署者抽查 |
| 非 Windows 平台 | 未适配 | ConPTY 仅 Windows（Win10 1809+）；其他平台未完整验证 |

## 部署安全清单

- [ ] `WEBHOST` 为 `127.0.0.1` 或 Tailscale 私网 IP，**绝不为** `0.0.0.0` / 公网 IP
- [ ] 生产环境设置了强随机 `WEBTOKEN`，访问时携带 `?token=`
- [ ] 防火墙/ACL 只对可信来源开放 `8788` 端口
- [ ] 服务账号遵循最小权限，避免以管理员身份常驻
- [ ] 定期检查 `audit.log`，核对每个会话的来源与行为
- [ ] 不使用时停止服务进程

## 安全相关变更的审查

涉及鉴权逻辑（WEBTOKEN 校验、1008 拒绝路径）、审计日志、PTY 会话生命周期、
绑定默认值的代码变更会被重点审查，参见 [CONTRIBUTING.md](CONTRIBUTING.md)
「安全相关贡献」一节。
